# <u>How to create a Desktop Window using JAVA:</u>
### Full Code:
```
import java.io.*;
import java.util.*;
import javax.swing.*;
public class WindowTest{
    public static void main(String[]args)throws IOException,InterruptedException{
        final JFrame textEditor=new JFrame("Page");
        final ImageIcon icon=new ImageIcon("G:\\ALL PROGRAM FILES\\JAVA_Intellij\\Projects\\Text_Editor\\Reference_Pictures\\Icons\\ChatGPT Image Sep 16, 2026, 04_58_03 PM.png");
        textEditor.setSize(1000,800);
        textEditor.setIconImage(icon.getImage());
        textEditor.setLocationRelativeTo(null);
        textEditor.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        textEditor.setResizable(true);
        textEditor.setVisible(true);
    }
}
```
---
## Explanation:
1. ### <u>JFrame</u>
- javax.swing.JFrame;/javax.swing.*; is used to import the JFrame class from the java library.
- JFrame creates the main window. 
- We create an object of the JFrame class.
- We pass the window title in the constructor as a String.
```
        textEditor.setSize(1000,800);
        textEditor.setLocationRelativeTo(null);
        textEditor.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        textEditor.setResizable(true);
        textEditor.setVisible(true);
```
- ***.setSize()*** method takes the ***WIDTH*** and ***HEIGHT*** as parameters and sets the default size of the window to the preferred dimensions.
    - ***WIDTH*** - Any integer value.
    - ***HEIGHT*** - Any integer value.
- .setLocationRelativeTo() method ensures that the position of the window on the screen is at a certain place. 
  - ***null*** as a parameter ensures that the window is at the centre.
- ***.setDefaultCloseOperation()*** ensures what the window does when we press the close ('X') button.
  - ***EXIT_ON_CLOSE*** closes the current instance of window and keeps other windows running.
